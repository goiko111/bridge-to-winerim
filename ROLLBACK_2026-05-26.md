## Rollback DB opcional

```sql
DROP INDEX IF EXISTS public.idx_stock_sync_log_line_variant_claim;
DROP INDEX IF EXISTS public.idx_stock_sync_log_stock_id;

  DROP COLUMN IF EXISTS idempotency_key,
  DROP COLUMN IF EXISTS stock_id,
  DROP COLUMN IF EXISTS variant;

DROP TABLE IF EXISTS public.user_roles;
```

## Validación tras rollback
```sql
SELECT status, count(*)
FROM public.stock_sync_log
WHERE created_at > now() - interval '2 hours'
GROUP BY status;

SELECT id, status, last_error, updated_at
FROM public.outbound_tasks
WHERE updated_at > now() - interval '2 hours'
ORDER BY updated_at DESC
LIMIT 50;
```
